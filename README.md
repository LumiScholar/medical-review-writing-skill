# medical-review-writing-skill

医学研究生课程综述写作规范与证据核查 Skill，适用于基础医学、临床医学、预防医学、公共卫生及其他医学相关主题。

## 文件导航

- [SKILL.md](SKILL.md)：主规范与完整写作流程。
- [任务信息单](references/assignment-brief.md)：每次新作业需提供的课程要求和材料。
- [结构与语言规范](references/style-and-structure.md)：论证结构、中文学术用语与模板化语言控制。
- [证据与引文核对规范](references/evidence-audit.md)：引用规范及具体论点与原文逐条对照。
- [全文终审清单](references/final-checklist.md)：交稿前的结构、证据、语言与格式检查。
- [技能界面信息](agents/openai.yaml)：技能名称和调用提示。

## 使用方式

将完整技能目录提供给AI助手，并附本次课程要求、论文主题或现有稿件。辅助规范通过相对路径引用，应与SKILL.md一起保留。

在支持Skill的环境中，按该环境的方式安装并调用 `graduate-review-writing`。也可以直接要求助手：

> 请按照此仓库中的SKILL.md完成医学课程综述写作，重点检查论证结构、学术表达、引用准确性以及关键论点与原文的对应关系。

本规范不预设疾病、课程格式或文章框架。每次论文均以当前作业要求为准；核查限制应如实说明，不承诺绝无错误或通过AI检测。

# 引用规范与论点原文对照

## 一 两项独立核查

**题录核查**确认文献存在及格式准确；**内容核查**确认具体论点被实际来源支持。找到DOI或正确题名，不等于完成内容核查。

按来源在论证中的作用选择材料：原始研究支持自身发现，系统评价支持其汇总估计，指南支持具体推荐。评论或其他综述可以支持概括性讨论，但不应被包装成原始实验或试验报告。

## 二 记录单位

以“可单独判断真伪和支持范围的论点”为单位，而不只按参考文献逐篇做总结。一篇文章可能需要核查多个不同论点，一个论点也可能需要多篇来源共同支持。

建议记录字段：

| 字段 | 记录内容 |
|---|---|
| 正文定位 | 章节及句子或段落的可识别内容 |
| 具体论点 | 数据、关系、机制、比较、定义或建议 |
| 来源身份 | 题名、作者、年份、DOI或其他可靠标识 |
| 原文位置 | 方法、结果、图表、补充材料或指南条款 |
| 对象与条件 | 生物系统、样本或人群、环境、时点及实验或研究条件 |
| 实际结果 | 原始比较、数值、区间、分析方法及必要限定 |
| 访问范围 | 正式全文、作者稿、摘要、间接来源或题录 |
| 对应判断 | 直接支持、部分支持、间接支持、不支持或尚未核实 |
| 修改处理 | 保留、限定、拆句、改引、删除或列为待核 |

不要把空表或检索到的条目数量当作已核实工作量。“未取得全文”是访问状态，不是证据不成立；“部分支持”则要求缩小论点或补充来源。

## 三 按研究性质选择核对项

### 共同项

研究问题与设计、对象或材料来源、条件与时间、主要比较、结果指标、分析范围、关键数值、偏倚和推论边界。区分主要结局、次要分析、探索性分析及作者讨论。

### 基础与机制研究

按需要核对物种、细胞或组织来源、模型、处理条件、剂量与时程、对照、重复层次及检测方法。区分表达变化、功能改变、直接相互作用、必要性或充分性证据；不把单一标记或富集结果写成机制已证实。区分独立生物学重复和技术重复，避免用检测次数代替独立样本量。

### 临床与人群研究

按需要核对纳入人群、分组、分析集、对照、终点定义、时间起点、随访、事件数、混杂调整与缺失处理。随机入组、完成研究、某一终点分析人数可能不同。基线暴露、时变暴露及个体内改变不能混同。

### 诊断、预测、组学与方法研究

按需要核对参考标准、阈值、数据划分、内部与外部验证、性能指标及其区间。区分诊断与预测、判别与校准、相关与可用性；关注数据泄漏、多重检验、模型过拟合及适用环境。不把发现阶段结果直接当作验证结论。

### 质性、实施或政策研究

按需要核对研究场景、参与者或资料选择、分析方法及结论迁移范围。主题或经验陈述不直接转化为发生率、因果效应或普遍适用的政策建议。

以上核对项按主题选用，不要求无关研究填写全部字段。

## 四 数字与统计解释

- 核对效应指标、单位、分母、方向、参照组、区间端点及调整模型，不混用不同指标。
- 区分组内与组间、绝对与相对、总体与亚组、预设与事后分析。
- 零假设检验未显著不证明无差异；亚组一显著一不显著不证明两亚组效果不同。
- 区分替代终点和实际临床或人群结局；复合终点应交代影响解释的组成部分。
- 保留效应大小与不确定性，不只选取P值。不得为显著性、整齐或篇幅改动数值。
- 单位换算需保留原始值与计算依据；示例换算不得写成论文或指南的建议。
- 多篇文章涉及同一研究、样本或数据集时记录关系，不能重复累计独立证据。

## 五 引用位置和格式

具体论点附近给出对应引文。一个句子若包含多个不同断言，必要时拆句或分别引用；段末一串文献不能掩盖部分论点没有来源的问题。

作者的综合推论可以由多项证据支持，但必须保持推论身份，不能暗示某篇原文已经直接得出同一结论。引用论文的背景或讨论中转述的研究时，应追溯原始文献；无法追溯时说明间接依据，避免假装已读原文。

逐条核对作者及机构作者、正式题名、年份、期刊、卷期、页码或文章号、DOI、版本和发表类型。留意网络首发与正式发表年份不同，补充刊、摘要号和预印本不能当作普通正式论文处理。缺失信息不能按常见格式猜填。

采用课程要求的顺序编码或作者年份制，全文一致。调整正文后复核引用与文末对应，不允许编号错位、条目指向错误或借用相近文献替代真实来源。

## 六 原文访问与核查限制

优先尝试正式开放版本、作者或机构存档及可用数据库。只看到摘要时，不声称核对了方法细节或全部分析；只拿到修订稿时，不声称逐字比对正式版。需要核查更正、撤稿或后续发表时，记录实际查到的状态，不能由“未检索到”推断绝不存在。

关键论点无法核实时，缩小论点、替换来源、删除或明确待核，不用流畅措辞遮盖。访问与核对记录保留在工作表，不把检索操作流水账塞进论文正文。

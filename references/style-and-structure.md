# 通用写作逻辑与中文学术表达

## 一 先建立论证关系

综述的核心是综合和评价已有知识，不是文献摘要合集。先明确文章要回答什么、证据支持到哪一步、仍有什么解释缺口，再决定章节。

提纲检查：

- 每节是否有独立问题？相邻标题是否重复、包含或无法区分？
- 章节组织是否有可解释的依据，而非临时把剩余内容拼在一起？
- 小标题能否概括其下全部主要内容？重要内容是否埋在不相符的标题下面？
- 基础概念、条件和指标是否先于后文分析说明？
- 证据描述、机制解释及应用建议是否保持适当层次？

不固定引言、方法、机制、临床应用等章节的数量和顺序。机制、技术进展、证据争议或转化问题是否独立成节，取决于核心问题、证据和篇幅。叙述性综述不必模仿原始研究的固定结构。

## 二 段落应推进判断

同一段中多项研究可以共同支持一个判断，也可以形成对比。关键是解释它们之间的关系，而不是依次介绍作者、样本和结论。

保留有助于判断的条件与数字，删去不影响比较的枝节。不同研究结果不一致时，检查研究对象、模型、干预或暴露、参照条件、终点、测量方式、分析及验证程度，避免用“存在异质性”替代分析。

局限讨论应说明具体影响。例如测量误差可能影响分类和效应估计，选择机制可能限制代表性，随访或实验时程可能不足以观察目标现象。不要每项研究后都追加同一句“样本量较小，仍需进一步研究”。

## 三 用语与证据强度对应

| 表达 | 使用前要确认 |
|---|---|
| 相关、伴随变化 | 是否仅为同时或序贯观察，是否存在替代解释 |
| 预测、判别 | 是否检验预测性能、验证范围及适用条件，而非只有相关性 |
| 参与、影响、调节 | 是否有相应功能验证，结果方向和对象是否明确 |
| 介导、机制 | 是否检验了中间过程及因果关系，而非只测到指标变化 |
| 导致、改善、降低风险 | 是否有足够的因果或干预证据，是否超出原研究范围 |
| 无效、相同、等效 | 是否有支持这些判断的设计与精确性，不能仅凭未显著 |
| 推荐、应当 | 是否来源于规范建议或充分证据；作者建议须标明性质 |

上述为核对方向，不是要求所有研究统一降格或一律使用保守措辞。充分支持的结论应明确写出，不为显得谨慎而制造不确定性。

## 四 控制模板化和对话化语言

将“AI语言控制”落实为准确性、具体性与篇章自然度检查，不设单词黑名单，不以检测器分数判断写作质量。

| 问题模式 | 修改方式 |
|---|---|
| 反复写“本文将……并……为……提供参考” | 范围说明保留在必要位置，其余写实际发现或判断 |
| 段段使用“该结果提示……仍需进一步研究” | 明确结果支持的范围及不足；没有新增信息时删句 |
| “值得注意的是”“此外”“因此”只负责接句 | 删除空衔接，或写清转折、递进与推论关系 |
| 连续写“具有重要意义”“提供新思路” | 说明改变了何种认识、解释了什么问题，不能说明则删除 |
| “我们写作时应核对……”“这个地方不能理解成……” | 操作建议移出正文；必要的学术判断直接陈述并给依据 |
| 所有段落长度、开头和结尾高度一致 | 按内容任务组织，不机械追求整齐或人为错落 |
| 用高级词、同义词轮换替代精确术语 | 固定关键术语，采用熟悉而明确的动词 |
| 结尾重复提纲并泛泛展望 | 回答核心问题，只保留有依据的研究缺口 |

避免过度对称、无意义排比和抽象词堆叠；也不要把规范的学术句式全部改成口语。句长服从信息关系，必要时拆分不同论点。

## 五 参照文献与作者声音

选择主题或文章类型相近、可核验的高质量中文综述，学习其问题组织、比较方式、术语与限定。不能只按“核心”标签照搬写法，更不能近距离改写其段落。

不虚构经历、判断、数据或不完美来模拟人工写作。不声明“纯人工撰写”或保证通过AI检测。论文中的作者判断应来自证据综合，而非助手与用户的写作对话。
